# Combat experience illustrations

Created with the built-in image_gen tool. The 256px transparent WebPs are the runtime deliverables, approximately 13–27 KB each (all ten total less than 200 KB). Drawing prompts and Bun’s species/style reference are recorded in [prompts.json](prompts.json). Large source PNGs and review screenshots are kept outside this runtime delivery.

| Asset | Use |
| --- | --- |
| rescue-bun | Bun, the snowhorn goat kid, safely tipped over in mud in the practice rescue |
| hazard-fire | Fire hazard |
| hazard-thorns | Thorn hazard |
| hazard-rift | Broken ground/rift hazard |
| exit-gate | Escape tiles |
| objective-hold | Ground to defend |
| objective-seal | Tear to close |
| reaction-hurt | Brief friendly impact accent |
| reaction-ready | Ready/protected accent |
| reaction-celebrate | Rescue, recovery and victory accent |

Phone and shared-board environment markers use the same art lookup. A rescued Bun uses the existing upright snowhorn-goat portrait. Unknown future captives retain their rescue glyph instead of borrowing Bun’s identity. Distinct hazard, exit and objective outlines, written rules and countdowns remain in place. Missing images fall back to the existing glyphs.

Phone combat events also play existing impact_strike, heal_bloom, guard_ward, miss_veer and burst_star sheets. The reaction accents sit over the existing hero portraits, preserving appearance across species, tier and equipment. These are brief pose/overlay reactions, not newly painted facial-expression sets. Effects do not hold inputs or extend presentation durations. Reduced-motion settings show a single complete effect frame and omit portrait motion.
