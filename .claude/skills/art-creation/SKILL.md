# Art creation

Follow [.agents/skills/art-creation/SKILL.md](../../../.agents/skills/art-creation/SKILL.md).
It is the one copy of these steps, shared with the agents that paint with the imagegen skill,
so they and you cannot drift apart.

The one difference for you: if you have no image generation tool, do every step except
generating. Find the owed path and its contract, write the prompt and its record, and give
the user the prompt to run. Then, when they hand you the image, fit it to the contract, run
the gates, get their approval, push it and commit the lock and the record.
