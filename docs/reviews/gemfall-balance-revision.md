# Gemfall story balance revision

Resumed the interrupted `codex/gemfall-story-balance` work and reviewed all sixteen variants against the [chapter cohesion skill](../../.claude/skills/chapter-cohesion/SKILL.md) and [Gemfall authoring contract](../campaigns/gemfall-authoring.md). This supersedes the activity quotas in the earlier [play-design audit](gemfall-play-design/audit.md).

The previous gate required four games in three kinds on every successful route. It rewarded another packing, copying or recap task even after the story had earned its result. This revision replaces **53 activities: 35 with story and 18 with ordinary choices and specific replies**. Retained games total 120 across all branches, down from 173; these are whole-file totals, not the number a family must play. Dice, consequences, rewards and combat remain. No chapter is required to contain all five modes.

## Saved games and consequences

- `resumeInteractions` stores the exact shipped interaction scenes under their original IDs. Fresh entry uses the replacement story/choice; only a persisted interaction prompt can use the retired contract. Success, failure and assistance still apply the original branches and effects, once the player continues.
- Scene hashes from the original dabee9d8 activities pin all 53 contracts. Tests serialize saves, finish real controls, retry, miss where supported, and assist at one/two/four seats. They compare branch destinations, flags, inventory/health, coins and XP against the original scenes.
- Existing check prompts, encounters, ending/road/setback/resumed-save digests remain unchanged. Re-pin file hashes because this is an owner-requested gameplay edit, not a wording-only edit.
- Ordinary responses show a character reply before applying the conversation result. Explicit help choices preserve the formerly assisted evidence flags; recovery flags written by old saves remain valid at their ending callbacks.
- The full-collection test driver now prefers an available honeycake exchange and agreed ledger transfer over a risky negotiation. New reply scenes change sequence-keyed dice. The existing minimum collection assertion stays intact.
- Graph proof regeneration changes Riftlight's checker fingerprint because the shared validator changed; its campaign fingerprint and explored state count remain unchanged.

## PR review follow-up: casual conversation participation

Fifteen low-stakes conversations now use `story` with branching choices. The current story-turn holder selects a response, and the character reply also continues without waiting for every phone. The purpose, quiet and verdict councils remain collective `choice_point` votes. Destinations, rewards, outcome effects and archived interactions are unchanged.

The regression tests submit a single real `applyIntent(CHOOSE)` at a four-hero table for all eighteen conversations. Casual choices immediately enter their reply and continue with one phone; council choices record one vote and remain pending. These tests bypass `send()`, which would automatically cast everyone's votes and hide the regression. Existing reply tests now cover both story choices and councils.

Follow-up validation: all **973 Gemfall tests pass** across 19 files, including real-server playthroughs and the unchanged campaign compatibility digests. Type checking, content validation (117 passes, four existing warnings), continuity (zero new/stale findings) and diff checks pass. The static pacing report was rerun; it cannot measure the time saved by removing compulsory all-phone stops. The full-suite result above belongs to the initial revision.
