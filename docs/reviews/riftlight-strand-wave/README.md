# Strand-wave visual checks

Actual local game captures, using the real server, client, Pixi stage and phone
World tab. A temporary isolated preview starts at the chapter under review (index
1 in that preview only), then uses a playtest jump to the decision. No shipped
campaign order, prerequisites, chapter index or household save was changed.

- [Wyrm Nest furniture decision, TV](supplies-tv.png)
- [Wyrm Nest furniture decision, phone](supplies-phone.png)
- [Squall Temple preparation decision, TV](gear-tv.png)
- [Squall Temple preparation decision, phone](gear-phone.png)

TV: 1920x1080. Phone: 390x844, one unicorn hero. The phone uses its existing guest
carousel. These captures check decision text and controls on the actual surfaces;
they are not a family timing or usability study. The tall builder retains the
existing partial overlap with the phone's guest bar; this pass does not change
stage layout.

Both scene illustrations are existing character-free settings, with reusable cast
cutouts rendered separately. After the nest encounter, furniture and reader scenes
show the builders/readers rather than bringing the wyrm back into the room it left.
No new bitmap artwork was required.
