# Final-wave visual checks

Actual local server/client captures, with the Pixi stage and phone World tab.
Each runs in a temporary isolated preview whose first chapter is the chapter under
review (index 1 in the preview only), then uses a playtest jump to the decision.
The preview seeds the two learned regional flags and the shared-chime/trust flags
so Orin's intervention can be photographed. Shipped prerequisites, order, index,
chapter files and household saves are not changed by the capture setup.
